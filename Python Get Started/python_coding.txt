<< Python Task 2: Find a longest word. >>


>> Junior level python coding:

> The Code:

def find_longest_word(sentence):
    words = sentence.split()
    longest_word = ""
    for word in words:
        if len(word) > len(longest_word):
            longest_word = word
    return longest_word



>> Senior level python coding:

> The Code:

def find_longest_word(sentence):
    return max(sentence.split(),
    key=len, default="")
